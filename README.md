# 🏥 Hospital Operations Analytics Dashboard

An end-to-end Business Intelligence project that analyzes hospital operational data to monitor patient admissions, bed occupancy, physician workload, and departmental performance. The dashboard was built in Power BI using Power Query, DAX, and relational data modeling to support KPI-driven decision making.

## Tech Stack
- Power BI
- Power Query (ETL)
- DAX
- Data Modeling
- Excel

## Business Objectives
- Monitor patient admission and discharge trends
- Track bed occupancy and resource utilization
- Evaluate department-wise operational performance
- Provide KPI scorecards for executive reporting

## Key KPIs
- Bed Occupancy Rate
- Average Length of Stay (ALOS)
- Patient Throughput
- Department Utilization
- Admission vs Discharge Trend
